A Blazor UI component library for application interfaces

Quark Suite brings the composition patterns of shadcn/ui to C# and Razor. Build forms with inputs and validation , display data with data tables and charts , and compose dialogs , navigation, and AI chat interfaces. Each component demo includes examples you can adapt to your Blazor application.

Start with the installation guide and build your first component . Learn how the CSS, icon, and theme generators prepare your assets, then customize typed styling properties and themes and dark mode . Visit the source repository or install Soenneker.Quark.Suite from NuGet .
