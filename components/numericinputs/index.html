NumericInput Component Properties

Properties inherited from Element base.

NumericInput Features

The NumericInput component inherits all properties from the Element base class plus:

  • Value: Numeric value (decimal, int, long, etc.)
  • Min: Minimum allowed value
  • Max: Maximum allowed value
  • Step: Step increment value
  • Placeholder: Placeholder text
  • ReadOnly: Read-only state
  • Disabled: Disabled state
  • Required: Required validation
  • AutoComplete: Auto-complete behavior
  • Event Handlers: Input, focus, blur, change events
