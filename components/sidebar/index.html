Sidebar

A composable, themeable and customizable sidebar component.

Sidebars are one of the most complex components to build. They are central to any application and often contain a lot of moving parts.

We now have a solid foundation to build on top of. Composable. Themeable. Customizable.

Composition

Use the following structure to build a sidebar layout. 

SidebarProvider ├── Sidebar │   ├── SidebarHeader │   ├── SidebarContent │   │   └── SidebarGroup │   │       ├── SidebarGroupLabel │   │       ├── SidebarGroupAction │   │       └── SidebarGroupContent │   │           └── SidebarMenu │   │               └── SidebarMenuItem │   │                   ├── SidebarMenuButton │   │                   ├── SidebarMenuAction │   │                   ├── SidebarMenuBadge │   │                   └── SidebarMenuSub │   ├── SidebarFooter │   └── SidebarRail ├── SidebarInset └── SidebarTrigger
  • `SidebarProvider` owns the shared open, mobile, and keyboard-shortcut state.
  • `Sidebar`, `SidebarHeader`, `SidebarContent`, and `SidebarFooter` form the actual shell.
  • `SidebarMenuButton`, `SidebarMenuAction`, `SidebarMenuBadge`, and `SidebarMenuSub` cover the menu composition.
  • `SidebarInset` and `SidebarTrigger` keep the main content area wired to the same provider.

This page exercises the core menu composition: button-as-child links, group action, menu action, badge, submenu, footer, and rail.

Adjust the sidebar width

On desktop, drag the right edge of the sidebar to make it wider or narrower. Refresh to try the saved width.

Enable resizing and persistence

Set Resizable to enable desktop resizing. MinResizeWidth and MaxResizeWidth are pixel limits. Bind ExpandedWidth to track the chosen width; null starts with the provider�s SidebarWidth. Set ResizeStorageKey to a unique localStorage key to restore the width after refreshing. A saved width takes precedence over the initial width and is clamped to the current limits. Arrow keys move the edge by 8 pixels, Shift accelerates to 32 pixels, and Home/End select the limits. Mobile drawers and collapsed sidebars do not show the resize handle. 

<SidebarProvider>     <Sidebar Resizable="true" Contained="true" Collapsible="SidebarCollapsible.Icon"              MinResizeWidth="192" MaxResizeWidth="400" ResizeStorageKey="quark-demo-sidebar-width" @bind-ExpandedWidth="_resizableWidth">         <!-- Sidebar content -->     </Sidebar>     <SidebarInset Padding="Padding.Is6" Gap="Gap.Is3">         <H3 TextSize="TextSize.Lg" FontWeight="FontWeight.Semibold">Workspace</H3>         <Paragraph TextSize="TextSize.Sm" aria-live="polite">             Expanded width: @($"{_resizableWidth ?? 256:0} px")         </Paragraph>         <!-- Workspace content -->     </SidebarInset> </SidebarProvider>  @code {     private double? _resizableWidth; }
