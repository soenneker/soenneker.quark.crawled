Link

Render a badge as a link with AsChild.
Open Link 
																			<Div Display="Display.Flex" FlexWrap="FlexWrap.Wrap" Gap="Gap.Is2">     <Badge Variant="BadgeVariant.Default" AsChild="true">         <Anchor Href="#link">             Open Link

Custom Colors

Add utility classes for product-specific emphasis.
Blue Green Sky Purple Red 
																			<Div Display="Display.Flex" FlexWrap="FlexWrap.Wrap" Gap="Gap.Is2">     <Badge Variant="BadgeVariant.Default" Class="!bg-blue-50 !text-blue-700 dark:!bg-blue-950 dark:!text-blue-300">Blue</Badge>     <Badge Variant="BadgeVariant.Default" Class="!bg-green-50 !text-green-700 dark:!bg-green-950 dark:!text-green-300">Green</Badge>     <Badge Variant="BadgeVariant.Default" Class="!bg-sky-50 !text-sky-700 dark:!bg-sky-950 dark:!text-sky-300">Sky</Badge>
