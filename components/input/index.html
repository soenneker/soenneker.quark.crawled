Input

A text input component for forms and user data entry with built-in styling and accessibility features.

Your API key is encrypted and stored securely.

																			<Field MaxWidth="MaxWidth.IsXs">     <FieldLabel For="input-api-key">API Key</FieldLabel>     <Input Id="input-api-key" Type="password" Placeholder="sk-..." />     <FieldDescription>Your API key is encrypted and stored securely.</FieldDescription>

Basic

																			<Input Placeholder="Enter text" />

Field

Use Field, FieldLabel, and FieldDescription to create an input with a label and description.

Choose a unique username for your account.

																			<Field MaxWidth="MaxWidth.IsXs">     <FieldLabel For="input-field-username">Username</FieldLabel>     <Input Id="input-field-username" Type="text" Placeholder="Enter your username" />     <FieldDescription>Choose a unique username for your account.</FieldDescription>

Field Group

Use FieldGroup to show multiple Field blocks and to build forms.

We'll send updates to this address.

																			<FieldGroup Width="Width.IsFull" MaxWidth="MaxWidth.IsXs">     <Field>         <FieldLabel For="fieldgroup-name">Name</FieldLabel>         <Input Id="fieldgroup-name" Type="text" Placeholder="Jordan Lee" />

Disabled

Use the disabled prop to disable the input. To style the disabled state, add the data-disabled attribute to the Field component.

This field is currently disabled.

																			<Field MaxWidth="MaxWidth.IsXs" Disabled="true">     <FieldLabel For="input-disabled">Email</FieldLabel>     <Input Id="input-disabled" Type="email" Placeholder="Email" Disabled="true" />     <FieldDescription>This field is currently disabled.</FieldDescription>

Invalid

Use the aria-invalid prop to mark the input as invalid. To style the invalid state, add the data-invalid attribute to the Field component.

This field contains validation errors.

																			<Field MaxWidth="MaxWidth.IsXs" IsInvalid="true">     <FieldLabel For="input-invalid">Invalid Input</FieldLabel>     <Input Id="input-invalid" Placeholder="Error" aria-invalid="true" />     <FieldDescription>This field contains validation errors.</FieldDescription>

File

Use the type="file" prop to create a file input.

Select a picture to upload.

																			<Field MaxWidth="MaxWidth.IsXs">     <FieldLabel For="picture">Picture</FieldLabel>     <Input Id="picture" Type="file" />     <FieldDescription>Select a picture to upload.</FieldDescription>

Inline

Use Field with orientation="horizontal" to create an inline input. Pair with Button to create a search input with a button. 
																			<Field  Orientation="@Orientation.Horizontal" MaxWidth="MaxWidth.IsXs" Width="Width.IsFull">     <Input Type="search" Placeholder="Search..." />     <Button Type="@ButtonType.Button" Variant="ButtonVariant.Default">Search</Button> </Field>

Grid

Use a grid layout to place multiple inputs side by side. 
																			<FieldGroup Class="grid-cols-2" Display="Display.Grid" Width="Width.IsFull" MaxWidth="MaxWidth.IsSm" Gap="Gap.Is4">     <Field>         <FieldLabel For="first-name">First Name</FieldLabel>         <Input Id="first-name" Type="text" Placeholder="Jordan" />

Required

Use the required attribute to indicate required inputs.

This field must be filled out.

																			<Field MaxWidth="MaxWidth.IsXs">     <FieldLabel For="input-required" RequiredIndicator="true">Required Field</FieldLabel>     <Input Id="input-required" Placeholder="This field is required" Required="true" />     <FieldDescription>This field must be filled out.</FieldDescription>

Badge

Use Badge in the label to highlight a recommended field. 
																			<Field MaxWidth="MaxWidth.IsXs">     <FieldLabel For="input-badge" Display="Display.Flex" Width="Width.IsFull" ItemsAlign="Items.Center" Gap="Gap.Is2">         Webhook URL         <Badge Variant="BadgeVariant.Secondary" Margin="Margin.FromLeft.Auto">Beta</Badge>

Input Group

To add icons, text, or buttons inside an input, use the InputGroup component. See the Input Group component for more examples.
https://
																			<Field MaxWidth="MaxWidth.IsXs">     <FieldLabel For="input-group-url">Website URL</FieldLabel>     <InputGroup>         <InputGroupAddon>https://</InputGroupAddon>

Button Group

To add buttons to an input, use the ButtonGroup component. See the Button Group component for more examples. 
																			<Field MaxWidth="MaxWidth.IsXs">     <FieldLabel For="input-button-group">Search</FieldLabel>     <ButtonGroup>         <Input Id="input-button-group" Placeholder="Type to search..." />
