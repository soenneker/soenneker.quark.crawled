Semantic HTML

Article

Represents a self-contained composition that is independently distributable.

Understanding Semantic HTML

Published January 15, 2024

Semantic elements provide meaning for search engines and assistive technologies.

Using <article>, <main>, and <aside> improves accessibility and SEO. 

																		<Article Border="Border.Is1" Padding="Padding.Is3" BackgroundColor="BackgroundColor.Muted" Rounded="Rounded.Lg">     <H3>Understanding Semantic HTML</H3>     <Paragraph TextColor="TextColor.MutedForeground">         <Small>Published January 15, 2024</Small>

Main

The dominant content of the document. One visible Main per page.

Main Content Area

The <main> element contains primary content. Exclude repeated elements like nav, header, footer.

Screen readers use main to jump to primary content. 

																		<Main Border="Border.Is1" Padding="Padding.Is4" BackgroundColor="BackgroundColor.Muted" Rounded="Rounded.Lg">     <H3>Main Content Area</H3>     <Paragraph>         The &lt;main&gt; element contains primary content. Exclude repeated elements like nav, header, footer.

Nav

Represents a section of navigation links.
  • Overview
  • Examples
  • Accessibility

Article + Aside

Aside represents tangentially related content (sidebars, pull quotes).

Main Article Content

Primary information the user came to read. The article continues with details and explanations.

Related Information

Did you know?

Aside is used for sidebars, pull quotes, or related links. 

<Article>     <H4>Main content</H4>     <Paragraph>Primary content.</Paragraph> </Article> <Aside>     <H6>Sidebar</H6>     <Paragraph>Related content.</Paragraph> </Aside>
																		<Div Display="Display.Grid" Gap="Gap.Is4" Class="lg:grid-cols-3">             <Div Class="lg:col-span-2">                 <Article Border="Border.Is1" Rounded="Rounded.Default" Padding="Padding.Is3" Class="rounded-lg" Height="Height.IsFull">                     <H4>Main Article Content</H4>

Multiple Articles

First Article

Self-contained content that could be syndicated independently.

Second Article

Each article represents a complete, independent piece of content.

Benefits

Semantic HTML improves:
  • Search engine understanding of structure
  • Accessibility for screen readers
  • Code readability and maintainability
