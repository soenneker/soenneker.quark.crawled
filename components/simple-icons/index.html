Simple Icons

Use the SimpleIcon primitive to render generated Simple Icons SVGs with Quark sizing, colors, and standard element attributes. Start with the brand icon setup guide for packages, provider registration, and a copyable example that the source scanner can discover. Runtime enum values alone do not guarantee that an SVG is included in the build.

Brand icons rendered through the Simple Icons primitive. Requires Soenneker.Quark.Gen.SimpleIcons and ISimpleIconsSvgProvider.

																			<Div Display="Display.Flex" FlexWrap="FlexWrap.Wrap" ItemsAlign="Items.Center" Gap="Gap.Is4">     <SimpleIcon Name="@SimpleIconEnum.Github" Size="Size.Is6" aria-label="GitHub"/>     <SimpleIcon Name="@SimpleIconEnum.Google" Size="Size.Is6" aria-label="Google"/>     <SimpleIcon Name="@SimpleIconEnum.Figma" Size="Size.Is6" aria-label="Figma"/>

Sizes

Use Quark size values. 
																			<Div Display="Display.Flex" FlexWrap="FlexWrap.Wrap" ItemsAlign="Items.Center" Gap='Gap.Token("6")'>     <SimpleIcon Name="@SimpleIconEnum.Github" Size="Size.Is4" aria-label="GitHub small"/>     <SimpleIcon Name="@SimpleIconEnum.Github" Size="Size.Is6" aria-label="GitHub medium"/>     <SimpleIcon Name="@SimpleIconEnum.Github" Size="Size.Is8" aria-label="GitHub large"/>

Themed

Simple Icons use currentColor, so text color utilities control the mark color. 
																			<Div Display="Display.Flex" FlexWrap="FlexWrap.Wrap" ItemsAlign="Items.Center" Gap="Gap.Is4">     <SimpleIcon Name="@SimpleIconEnum.Github" Size="Size.Is7" TextColor="TextColor.Primary" aria-label="GitHub"/>     <SimpleIcon Name="@SimpleIconEnum.React" Size="Size.Is7" TextColor='TextColor.Token("sky-500")' aria-label="React"/>     <SimpleIcon Name="@SimpleIconEnum.Typescript" Size="Size.Is7" TextColor='TextColor.Token("blue-600")' aria-label="TypeScript"/>

In Buttons

Pair brand marks with button text for provider and integration actions. 
																			<Div Display="Display.Flex" FlexWrap="FlexWrap.Wrap" Gap="Gap.Is3">     <Button Variant="ButtonVariant.Outline">         <SimpleIcon Name="@SimpleIconEnum.Github" Size="Size.Is4" Margin="Margin.FromEnd.Is2" aria-hidden="true"/>         GitHub
