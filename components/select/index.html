Select

Displays a list of options for the user to pick from—triggered by a button.

																			<Select TValue="string" @bind-SelectedValue="_selectedFruit">     <SelectTrigger Width="Width.IsFull" MaxWidth='MaxWidth.Token("48")'>         <SelectValue Placeholder="Select a fruit" />     </SelectTrigger>

Align Item With Trigger

Use the position prop on SelectContent to control alignment. When position="item-aligned" (default), the popup positions so the selected item appears over the trigger. When position="popper", the popup aligns to the trigger edge.

Toggle to align the item with the trigger.

																			<FieldGroup MaxWidth="MaxWidth.IsXs">     <Field Orientation="@Orientation.Horizontal">         <FieldContent>             <FieldLabel For="select-align-item">Align Item</FieldLabel>

Groups

Use SelectGroup, SelectLabel, and SelectSeparator to organize items. 
																			<Select TValue="string" @bind-SelectedValue="_selectedProduce">     <SelectTrigger Width="Width.IsFull" MaxWidth='MaxWidth.Token("48")'>         <SelectValue Placeholder="Select a fruit" />     </SelectTrigger>

Scrollable

A select with many items that scrolls. 
																			<Select TValue="string" @bind-SelectedValue="_selectedTimezone">     <SelectTrigger Width="Width.IsFull" MaxWidth='MaxWidth.Token("64")'>         <SelectValue Placeholder="Select a timezone" />     </SelectTrigger>

Disabled

																			<Select TValue="string" Disabled="true">     <SelectTrigger Width="Width.IsFull" MaxWidth='MaxWidth.Token("48")'>         <SelectValue Placeholder="Select a fruit" />     </SelectTrigger>

Invalid

Add the data-invalid attribute to the Field component and the aria-invalid attribute to the SelectTrigger component to show an error state.
Please select a fruit.
																			<Field IsInvalid="true" Width="Width.IsFull" MaxWidth='MaxWidth.Token("48")'>     <FieldLabel>Fruit</FieldLabel>     <Select TValue="string">         <SelectTrigger aria-invalid="true">

RTL

To enable RTL support in shadcn/ui, see the RTL configuration guide. 
																			<DirectionProvider Dir="rtl">     <Div Width="Width.IsFull" Display="Display.Flex" Justify="Justify.Center">         <Select TValue="string" @bind-SelectedValue="_selectedRtlFruit">             <SelectTrigger Width="Width.Is32">
